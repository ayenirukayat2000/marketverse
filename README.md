
MarketVerse - Decentralized NFT Exchange
MarketVerse is a robust SIP-009 NFT marketplace smart contract for the Stacks blockchain. It enables users to list, buy, and sell NFTs with support for royalties, bidding, and extended features. The contract ensures secure ownership transfers, royalty payments, and a transparent bidding system.

Features
NFT Listing & Trading: List SIP-009 NFTs for sale and securely transfer ownership.
Royalties: Set and enforce royalty rates for NFT creators.
Bidding System: Place and accept bids on listed NFTs.
Ownership Checks: Only NFT owners can list or cancel listings.
Error Handling: Comprehensive error codes for invalid actions.
Secure Transfers: All STX and NFT transfers are validated and atomic.
Usage
Deploy the contract on the Stacks blockchain using Clarinet. Interact with the contract functions to list, buy, bid, and manage NFTs.
